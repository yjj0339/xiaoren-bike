# 🚲 小人骑车 · 清晨骑行

一个明快清新风格的"小人骑车"网页动画：戴青绿色头盔的小人蹬着珊瑚红自行车，在清晨的乡间小路一路向前。

**线上地址：<https://yjj0339.github.io/xiaoren-bike/>**

![二维码](qr-live.png)

手机扫上方二维码即可打开。

## 玩法 / 交互

| 操作 | 效果 |
| --- | --- |
| 点击画面 / 空格 / 🔔按钮 | 按车铃，"叮铃～"气泡 + WebAudio 合成铃声 |
| 按住画面 / → 键 / ↑ 键 | 加速冲刺：身体前倾、围巾飞起、轮下扬尘、速度线 |
| 松开 | 回到巡航速度 |

右上角实时显示速度（km/h）和里程（km）。

## 画面与实现要点

- **纯 Canvas 2D 手绘，单文件零依赖**（`index.html` 一个文件就是全部）
- **双腿两骨骼 IK 实时解算**：脚锁在踏板上，膝盖朝向正确，曲柄转一圈腿真踩一圈
- **双臂两骨骼 IK**：手握车把，冲刺时躯干前倾由 IK 自然吸收
- **围巾带状飘动**：分段正弦 flutter，速度越快飘得越平
- **七层视差**：太阳 / 云 / 小鸟 / 两重远山 / 树·松·灌木·小房子 / 路面虚线 / 前景野花
- **车轮辐条真实滚动**：角速度 = 距离 ÷ 半径，牙盘 0.5 齿比联动踏频
- 车架、车把、车铃、链条、车座、辐条、飞轮全部手绘
