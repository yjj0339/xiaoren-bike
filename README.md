# 🚲 小人骑车 · 清晨骑行

一个明快清新风格的"小人骑车"网页动画：戴青绿色头盔的小人蹬着珊瑚红自行车，一路向前，沿途景色从晨光骑到正午再骑进暖阳。

**线上地址：<https://yjj0339.github.io/xiaoren-bike/>**

![二维码](qr-live.png)

手机扫上方二维码即可打开。

## 玩法 / 交互

| 操作 | 效果 |
| --- | --- |
| 单击画面 / 空格 / 🔔按钮 | 按车铃，"叮铃～"气泡 + WebAudio 合成铃声 |
| 双击画面 / ↑ 键 | 整车跳一下，落地扬起尘土 |
| 按住画面 / → 键 | 加速冲刺：身体前倾、围巾飞起、轮下扬尘、速度线、车轮残影 |
| 每骑满 1 公里 | 顶部落彩纸 + "已骑 X 公里"横幅 |

右上角实时显示速度（km/h，冲刺时变橙）和里程（km）。

## 画面与实现要点

- **纯 Canvas 2D 手绘，单文件零依赖**（`index.html` 一个文件就是全部）
- **双腿两骨骼 IK 实时解算**：脚锁在踏板上，膝盖朝向正确，曲柄转一圈腿真踩一圈
- **双臂两骨骼 IK**：手握车把，冲刺/跳跃时躯干前倾由 IK 自然吸收
- **围巾带状飘动**：分段正弦 flutter，速度越快飘得越平
- **三段景色循环渐变**（v1.1）：晨光金 → 正午蓝 → 暖阳杏，天空/太阳/山丘/树木全调色板平滑过渡，永不发暗
- **八层视差**：太阳 / 云 / 小鸟 / 热气球 / 两重远山 / 树·松·灌木·小房子·风车 / 路面虚线 / 前景野花
- **小细节**：小人会眨眼、轻轻点头；蝴蝶在路边飞舞；风车叶片转动
- **车轮辐条真实滚动**：角速度 = 距离 ÷ 半径，牙盘 0.5 齿比联动踏频；冲刺时辐条出现运动残影
